Styles the admin, the editor canvas's overlays and toolbar, and the forms, media, menu and seo admin screens through classes and CSS custom properties instead of inline styles. The canvas outlines now use a `canvas-selection` theme token, and the editor's "can't place here" notice uses the admin's standard small text and shadow.
