Moves rendering and sync to the event and filter API. `render` and `sync` are exported from `plumix/plugin`. `render.document` is the async filter on a page's document, handed `(manifest, { data, title }, ctx)`; on an error page, a throwing handler is logged and the page renders its unfiltered document. `render.single`, `render.archive`, `render.term`, `render.author`, `render.date`, `render.frontPage` and `render.search` are the filters on a page's data, and `render.archiveEntries` is the sync filter that narrows an archive's entry query, handed `(query, { archive, params }, ctx)`; core still reapplies the public-entries rule after it. `sync.after` is the event emitted on the target after a sync, and a handler that throws is reported in the settle report without stopping the others or the CDN purge. `HookRegistry` gains `getEventHandlers(event)`.

Breaking: the `render:document`, `resolve:single:data`, `resolve:archive:data`, `resolve:term:data`, `resolve:author:data`, `resolve:date:data`, `resolve:front-page:data`, `resolve:search:data`, `archive:entries` and `sync:after` string names are removed. Replace `addFilter("render:document", (manifest, data, ctx, title) => …)` with `ctx.filters.add(render.document, (manifest, { data, title }, ctx) => …)`, `addFilter("resolve:<kind>:data", …)` with `ctx.filters.add(render.<kind>, …)`, `addFilter("archive:entries", (query, archive, params) => …)` with `ctx.filters.add(render.archiveEntries, (query, { archive, params }) => …)`, and `addAction("sync:after", …)` with `ctx.events.on(sync.after, …)`. A handler that ordered itself last with `priority` uses `{ order: "late" }`. `ArchiveReader` takes `filters` where it took `hooks`.
