Moves entries and terms to the event and filter API. `entry` and `term` are exported from `plumix/plugin`. `entry` holds `published`, `updated`, `trashed`, `restored`, `deleted`, `transition`, `revisionCreated`, `revisionPruned`, `revisionRestored`, `autosaveSaved`, `autosaveDiscarded` and `metaChanged`, the async filter `beforeSave`, and the procedures' input and output filters under `entry.rpc` (`entry.rpc.create.input`, `entry.rpc.get.output`, …). `term` holds `created`, `updated`, `deleted` and `metaChanged`, and its procedures' filters under `term.rpc`. Payloads are objects: `{ entry }`, `{ entry, previous }`, `{ entry, previousStatus }`, `{ term }`, `{ term, previous }`, and handlers receive the request's `ctx` second. `registerEntryType` and `registerTermTaxonomy` now return the type's or taxonomy's own events, the same as `entry.for(type)` and `term.for(taxonomy)`, so `const product = ctx.registerEntryType("product", …)` exposes `product.published` and `product.beforeSave`. Each event is emitted once and runs both the scoped and the unscoped handlers; at the same `order`, scoped handlers run first. A scope naming no registered entry type or taxonomy fails boot and lists the registered names.

Breaking: the `entry:*`, `entry:<type>:*`, `term:*`, `rpc:entry.*` and `rpc:term.*` string names are removed. Replace `addAction("entry:published", (entry, ctx) => …)` with `ctx.events.on(entry.published, ({ entry }, ctx) => …)`, `addAction("entry:<type>:published", …)` with `ctx.events.on(entry.for("<type>").published, …)`, `addAction("entry:transition", (entry, oldStatus) => …)` with `ctx.events.on(entry.transition, ({ entry, previousStatus }) => …)`, `addFilter("entry:before_save", …)` and `addFilter("entry:<type>:before_save", …)` with `ctx.filters.add(entry.beforeSave, …)` and `ctx.filters.add(entry.for("<type>").beforeSave, …)`, and `addFilter("rpc:entry.create:input", …)` with `ctx.filters.add(entry.rpc.create.input, …)`. Snake-case names become camel case: `revision_created` is `revisionCreated`, `meta_changed` is `metaChanged`. A subscription to `entry:<type>:*` for a type nothing registers, which used to never fire, now fails boot.
