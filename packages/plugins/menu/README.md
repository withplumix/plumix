# @plumix/plugin-menu

Navigation menus for Plumix, built from entries, terms and custom URLs.

## Install

```bash
pnpm add @plumix/plugin-menu
```

## Documentation

Read the [documentation](https://docs.plumix.dev/plugins/menu/) on docs.plumix.dev.
