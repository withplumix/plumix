# @plumix/plugin-feeds

RSS and Atom feeds for every public archive of a Plumix site.

## Install

```bash
pnpm add @plumix/plugin-feeds
```

## Documentation

Read the [documentation](https://docs.plumix.dev/plugins/feeds/) on docs.plumix.dev.
