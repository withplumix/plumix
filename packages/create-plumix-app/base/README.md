# __PROJECT_NAME__

A [Plumix](https://github.com/withplumix/plumix) site.

## Develop

```sh
pnpm dev
```

Then open the admin at `/_plumix/admin`.

## Build

```sh
pnpm build
```

## Test

```sh
pnpm test
```

Unit tests sit beside their source under `src/`, and feature tests, which boot the site and drive it, live in `tests/feature/`.
